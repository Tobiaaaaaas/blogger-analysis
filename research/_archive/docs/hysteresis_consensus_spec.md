## 1. 定稿口径与参数（含现役 / 对照变体）

| 项 | 值 |
|---|---|
| 对象 | swing 波段板 21 人（`PANELS["swing"]`）· 上证指数（`IDX_DEFAULT`） |
| 判定节奏 | 每**干净交易日**一次 **14:30** 快照定调 |
| 观点态 | { 多(+1) , 空(−1) , 无观点 } —— **无 mixed、无中性** |
| "波段观点" | 窗口 w 内该博主**时间序最新一条波段候选**的方向；窗口内没有 → 无观点 |
| 候选周期 | repo 板块归属不变（today/t1→short，其余→swing，**含 long**）；波段候选 = swing 中 **spec≠long**——即除 today/t1/long 外全档（t2/t3/t5/week/nweek_*/month 及 d: 定日档），无其它剔除 |
| 分母 e | 当日**有波段观点**的博主数 = 多 + 空（无观点者不计；剔 long 后 e 低于含 long 旧值） |
| 窗口 w | **5 交易日**（决策日前第 5 交易日 00:00 → 决策 14:30 前，墙钟含周末帖） |
| 看多比例 ρ | = **多方观点 / e**（看空比例 = 1−ρ = 空方观点/e，互补）——开/平/持所有条件以它为唯一自变量 |
| 成交/模式 | 决策日 **15:00 收盘**成交 · `long` 仅做多 / `both` 双向（指数期货式，未计融券费/保证金）· 0 成本、全仓 0/1 |
| 净值/基准 | 收盘→收盘；样本末持仓按末日收盘强制平 · 买持 = 同期首/末干净日收盘 |

中性态**暂不启用**（语料无中性标签，真·中性须 data/posts 原文重抽 —— 另立任务，§7）。

**阈值参数（空头阈值 = 多头镜像派生，改多头即两腿同动）**

| 参数 | 值 | 触发条件（ρ 轴） |
|---|---|---|
| 多头开仓 `TO_LONG` | **2/3** | ρ **>** TO_LONG → 开多 |
| 空头开仓 `TO_SHORT` | **1 − TO_LONG = 1/3** | ρ **<** TO_SHORT → 开空（= 看空比例 > 2/3） |
| 多头平仓 `TX_LONG` | **1/2** | 持多：ρ **<** TX_LONG（且 e>Q_exit）→ 平多 |
| 空头平仓 `TX_SHORT` | **1 − TX_LONG = 1/2** | 持空：ρ **>** TX_SHORT（且 e>Q_exit）→ 平空（= 看空比例 < 1/2） |
| 开仓法定人数 `Q_open` | **10** | 开仓判定需 e **>** Q_open（严格）；不足 → 当日不开、空仓持币 |
| 平仓法定人数 `Q_exit` | **10** | 平仓判定需 e **>** Q_exit；不足 → 当日不平、持仓维持（走滞回） |
| 滞回带 | 多 ρ∈[TX_LONG, TO_LONG]、空 ρ∈[TO_SHORT, TX_SHORT] | 越过开仓线不离场，ρ 越 1/2 反侧才平；恰 1/2 在带内 = 不平 |

运行变体：模式 `long` / `both`（上表）；法定人数 **Q10 现役** / `fixed`(0,0) 无门槛仅作敏感性对照
（`run_hyst` 变体，§6 给两档对比）。

## 2. 状态机与整数判定

```
当日判定，输入：现持仓 pos∈{0,±1}，当日 e、多方观点 bull → ρ = bull/e。条件全落 ρ 轴（阈值见 §1），
整数比较见下、不用 float。

平仓门（先判持仓腿，防薄日把"退潮"误当可动作信号）：
  持多 且 ρ < TX_LONG 且 e > Q_exit  → 平多（目标 0）
  持空 且 ρ > TX_SHORT 且 e > Q_exit → 平空（目标 0）
  e ≤ Q_exit                          → 该日不平，走下方滞回判定（薄日不认退潮/翻转）
开仓/换向门（空仓、或已过平仓门后）：
  e > Q_open 才看方向；不足 → 不开（空仓保持持币）：
    ρ > TO_LONG  → 目标多
    ρ < TO_SHORT → 目标空（both 模式；long 模式只平多持币、不开空）
  两门都过且目标与原仓反向 → 同收盘换向；只过平门 → 平至持币
滞回持有（未平时的默认）：持多 且 ρ ≥ TX_LONG 续持多 / 持空 且 ρ ≤ TX_SHORT 续持空（均含恰 50%）
```

- `long` 模式 pos∈{0,1}：只看多腿；ρ<TO_SHORT（= 看空比例 > 2/3）只触发平多持币、**不开空**。
- 整数比较（以现值 2/3、1/2 展开，改阈值就同步换分母）：
  开多 ρ>2/3 ⇔ `3·bull > 2·e`；开空 ρ<1/3 ⇔ `3·bull < e`（= `3·bear > 2·e`）；
  平多 ρ<1/2 ⇔ `2·bull < e`；平空 ρ>1/2 ⇔ `2·bull > e`（= `2·bear < e`）；
  续持多 ρ≥1/2 ⇔ `2·bull ≥ e`；续持空 ρ≤1/2 ⇔ `2·bull ≤ e`。恰 50%（`2·bull = e`，仅偶数 e 日）落两腿
  各自的**持**侧：五五开既非新共识、也非退潮，不平不开。
- Q_open / Q_exit 一律 **e 严格 > 法定人数**（无填充，也没有"e=Q 也可"；开仓门数值天然覆盖 `MIN_EXPRESSED(=3)`）；
  换向 = 平旧 + 开新，两门**分开判**（可设不同值）——只满足其一 → 平至持币或维持持仓。

## 3. 关键语义（为什么这样定）

- **单条 last → 构造上无 mixed**：每博主当日只取一条波段观点（时间序最新一条），同一个人不可能一天既多又空，
  旧 poll 的"同分钟多向并存 → mixed"概念取消（同 pub 次级序细节见 §4）。
- **两腿一把尺：看多比例**：所有条件只落在 ρ 一根轴上，看空比例 = 1−ρ 只是互补写法（空腿条件写成对称句）；
  空头阈值恒为多头镜像 → 两腿在各自比例上过同一条线。**不引入"支持率"叫法**；恰 1/2 落两腿滞回持侧。
- **开/平双法定人数、无填充**：开、平各设门槛，目的都是"表态人太少 → 比例不可信"。e 不过对应门 = **当日不动作**
  （开仓门不过 → 空仓持币；平仓门不过 → 持仓走滞回）。**不做任何 50% 填充/冻结合成**（早前 k=10「e<10 → 按
  50% 计 → 冻结」整套取消）。
- **两门独立参数化**：开仓要"足够多人"才信**新共识**，平仓也要"足够多人"才认**退潮/翻转**。两值现同设 10/10，
  可各自调整——数值与"e 严格 > Q"边界在 §1 定稿，重跑前只改那一行。
- **剔 long**：spec `long` 是单帖里的长线目标档，不代表波段观点 → 候选剔 spec=long（与运行模式名 `long`＝仅做多
  两个维度、同名无关）；同帖若另有 t*/week 等波段行仍照常计。

## 4. 观点生成（数据链路：signals → 每博主一条波段观点）

1. **语料**：[research/signals/](../research/signals/)（30 人，只用 swing 21）。行含 `d∈{±1}`、`spec`、`cat`、
   `board`、`target`、`pub`（分钟，**无秒级时间**）…… **没有 d=0、没有中性标签**。
2. **装载过滤**：`CorpusIndex` 按 `idx=="上证指数"` 装载（[research/poll.py](../research/poll.py)）；`board_of_spec`：
   today/t1→short，其余→swing（**含 long**，long 剔在取票步）。
3. **窗口 w**：起点 = `n_trading_days_ago(决策日, w)` 的 00:00；候选 `pub ∈ [起点, 决策时刻)`。`WINDOW_TRADING_DAYS`
   在 poll 内逐决策日**实时读**（[research/poll.py](../research/poll.py)）→ 换 w 只需运行前置
   `config.WINDOW_TRADING_DAYS["swing"] = w`。
4. **取票（单条 last）**：窗口内取该博主全部波段候选 = 板块 swing 且 **spec≠long**、目标未过（target=None 恒活；
   为日期时 `target ≥ 决策日`）。候选按 `pub` 升序、**同 pub 按语料行序**（无秒级时间的稳定次级序）**取最后一条**
   = "最新" → 其 `d` 即该博主当日波段观点。剔 long 后个别日由"原取 long 行"变"取次新波段行"，方向随之改变。
5. **无观点 / 干净日**：窗口内无波段候选（没发方向帖 / 只剩 today·t1 或 long / 目标全过期）→ 不进分母；博主有
   真实帖但抽取未追到（LP>LS 且其帖可能入窗）→ 该日整档不干净、不入样本。干净日判定只关乎抽取覆盖、不随剔 long
   改变；w=5 的干净日数与区间以 §6 注记 / `--check` 打印为准。

**代码同步状态（2026-09-04）**：已按本档语义全量代码化 —— poll 单条 last + 剔 spec=long + 无 mixed
（[research/poll.py](../research/poll.py)）；hyst 开/平双门 e>Q_open / e>Q_exit、无任何 50% 填充/冻结
（[research/combo/hyst.py](../research/combo/hyst.py)）；阈值与 Q 由 [research/config.py](../research/config.py)
的 HYST_* 单源（TO_LONG=2/3、TX_LONG=1/2、Q_open=Q_exit=10）。§6 即按本档语义重跑结果。

## 5. 执行与指标

- **网格**：[research/combo/daygrid.py](../research/combo/daygrid.py) `build_contexts()` 对样本干净日各取一次
  14:30 快照 → `DayContext{date, clean_idx, expressed, bull, bear, ref, …}`；**全部变体共享同一份上下文**。
- **净值**：14:30 定调 → 当日 **15:00 收盘成交**；`close_i → close_{i+1}` 的涨跌由收盘后目标持仓承担，决策日自己
  的 K 不承担该日涨跌（无未来函数）。样本末未平 → 末日收盘强制平。
- **指标口径**（`hyst.metrics`，镜像 [research/backtest/backtest.py](../research/backtest/backtest.py) `compute_stats`）：

| 指标 | 口径 |
|---|---|
| 累计 / 年化 | `nav[-1]−1` · `(1+累计)^(252/n)−1` |
| 日 Sharpe | `mean(日收益)/std(日收益, ddof=1) × √252` |
| 超额 / MDD | 累计 − 买持（首/末干净日收盘锚）· 净值峰值回撤最大 |
| 往返 / 胜率 | 已平仓腿（多/空分列）· `_signed_move>0` 占比（空腿按跌幅记正） |
| 在场 / 平均持仓 | `pos_after≠0` 的收盘后根数及 /(n−1) · mean(`exit_idx−entry_idx`) |
