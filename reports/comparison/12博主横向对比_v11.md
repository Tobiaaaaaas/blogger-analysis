## 一、研究说明

### 1.1 方法论版本

v11 沿用 A/B/C/D 双因子打分体系。每一条信号根据所在线段方向（上升段/下降段）和信号方向（看多/看空）归入四种场景：

| 场景 | 线段方向 | 信号方向 | 公式 |
|:---|:---|:---|:---|
| **A** | 上升段 | 看多 | `score = strength_base x max(return, short_return)` |
| **B** | 上升段 | 看空 | short_return > 1.5% 则 `+strength_base x short_return`；否则 `-strength_base x return` |
| **C** | 下降段 | 看多 | short_return > 1.5% 则 `+strength_base x short_return`；否则 `-strength_base x return` |
| **D** | 下降段 | 看空 | `score = strength_base x max(return, short_return)` |

- **return 因子**：信号参考价到所在线段下一拐点的潜在最大收益
- **short_return 因子**：T日起连续3个交易日平均收盘价相对于参考价的变动
- **strength_base**：strong = 2，moderate = 1
- 14个分数 = 7个总得分（综合/上升段/下降段/抄底/逃顶/看多/看空）+ 7个平均分

### 1.2 2026年市场走势回顾

2026年开局于牛市尾部的上升惯性，随后进入牛熊转换 + 高频震荡下行模式：

```
I9(3816) → I10(4191) ↑ 上升 → I11(4003) ↓ 下降 → I12(4197) ↑ 上升
→ M5(3795) ↓ 暴跌(-9.6%) → M6(4259) ↑ 强力反弹(+12.2%)
→ I13(3928) ↓ 下降 → I14(4175) ↑ 反弹 → M8(3741) ↓ 暴跌(-10.4%)
→ 当前(3770±) 企稳
```

**核心特征**：全年无单边趋势，多空快速切换。上升段和下降段交替频繁，对博主的双向判断能力要求极高。

## 八、核心发现

### 1. 2026熊市是照妖镜

v10时代（含2024-2025牛市），鸟瞰股市排名#2，凸教授的高分被解释为"超额收益能力"。v11剥离牛市后：

- 鸟瞰股市 #2 → #10（跌8位）
- 大盘蜂向标 新入 → #2
- 衡山佛曰论股 新入 → #3

**牛市中的"优秀"不等于熊市中的"可靠"。** 在牛市中看多即可获利，不需要逃顶能力。2026年的震荡下跌市场把逃顶和看空能力变成了生存必需品。

### 2. 双向能力是2026年唯一可靠的衡量标准

11位博主中仅有3位实现了上升段和下降段双正向。这揭示了一个残酷的事实：**2024-2025年牛市培养了太多"顺势喊多"型博主。** 当市场方向逆转，他们要么沉默（鸟瞰股市），要么坚持错误的偏多方向（稀豹、凸教授）。

### 3. 大盘蜂向标 — 2026全能冠军

唯一在14个维度全部取得正分的博主。他的框架（恐慌指数 + 技术形态 + 资金流向）在2026年多空快速轮动的市场中展现了极强的适应性。看多+1.69%、看空+1.67%几乎完全对称，说明他的体系不存在方向偏好。

### 4. 衡山佛曰论股 — 真正的熊市导航者

下降段+3.08%全场最高，但他并非简单"永不做多"（B:S=255:388，仍有一定看多比例）。他的看多信号质量同样很高（+1.67%，72.88%胜率）。他的成功在于正确地判断了**何时做多、何时做空** — 这正是区分专业与业余的关键。

### 5. 凸教授仍是综合第一，但暗藏杀机

+2.08%的综合平均分依然全场最高，但这是以承受-7.07%的下降段亏损为代价的。如果2026年下半年市场继续下行，他的综合分数将进一步被拖累。跟随凸教授的前提是：**你必须自己判断市场方向**，只在上升趋势中采纳他的看多信号。

### 6. 逃顶能力是真正的分水岭

11位博主中，只有衡山佛曰论股（38条）、TL阳光（24条）、梦若神机（23条）具备可靠的逃顶能力。凸教授和稀豹的逃顶信号数为零 — 他们永远不会告诉你"该卖了"。**在2026年这样的市场，没有逃顶能力的博主对跟随者是危险的。**

### 7. 看空的胜率直接反映专业水平

看空胜率>60%的仅有四位：大盘蜂向标（62.14%）、衡山佛曰论股（62.05%）、吉星高照（61.54%）、顺应周期（61.04%）。他们都同时具备看多和看空的正向能力。**"能在下跌中赚钱"是区分真假能力的终极标准。**

### 8. 稀豹系统性失败 — 应彻底移除

综合-1.32%，四time_horizon全负，看多-1.81%，看空仅+0.77%且胜率47%。他是唯一在所有维度均无亮点的博主。在v10牛市中他或许有可圈可点之处，但2026年证明他无法适应市场方向变化。
