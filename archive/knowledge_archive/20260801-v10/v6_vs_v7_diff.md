# v6 → v7 评估方法论升级说明

> 2026-07-31

---

## 一、为什么要升级？

v6 解决了"信号太少"的问题（18-53 → 94-905 条/人），但引入了两个新问题：

### 问题 1：描述性语言被误提为信号
`extract_signals.py` 的关键词匹配过于激进。"大盘上涨"只要出现在帖子里就被标为 bullish 信号——但博主可能只是在描述今天发生了什么，并非预测。

**例子**：
- "今天大盘上涨2%，成交量放大" → 这是**描述**，不是预测
- "我采用保守策略，先落袋为安" → 这是**自我操作描述**，不是方向判断
- "不必焦虑，市场不符合口味" → 这是**心理按摩**，不是信号

这些帖子在 v6 中被当作 moderate + directional_clear 信号计入评分，稀释了真正的预测能力评估。

### 问题 2：所有信号用同一套时间窗口评估
v6 对每条信号都用 T+5/10/15/20 评估，但实际上：

| 博主 | short-term 占比 | 问题 |
|------|:------:|------|
| 鸟瞰股市 | **92%** | T+20 评估"明天"预测→噪音 |
| 凸教授 | **78%** | 短线选手被中长期窗口惩罚 |
| TL阳光 | **71%** | "明天看涨/跌"在 T+20 早已过期 |
| 衡山佛 | **12% long** | 长线判断在 T+5 被误判为失败 |

**核心矛盾**：一个"明天看涨"的帖子在 20 天后的市场表现，和博主的判断力毫无关系——他的信号有效期只有 1-2 天。

## 二、v7 改了什么？

### 改进 1：预测意图检测

新增 `predictive` 字段，区分**预测**和**描述**：

| | 预测性（计入评分） | 描述性（排除） |
|---|---|---|
| 特征 | 含"将/会/预计/目标/有望/大概率"等前瞻词 | 纯描述今日行情 |
| | 含"明天/下周/年底"等时间锚点 | 心理按摩/鸡汤 |
| | 含"买入/卖出/加仓/减仓"等操作指令 | 自我操作描述无方向指引 |
| 标记 | `specific: "explicit_action"` 或 `"directional_clear"` | `specific: "descriptive"` ❌ |

**效果**：
- 顺应周期：150 条心理按摩类帖子被正确排除（v6 中当作信号）
- 奔走的股票：105 条描述性内容被排除
- 云帆观市：84 条被排除
- 大多数博主减少 3-18% 的描述性噪音

### 改进 2：时间维度标注

新增 `time_horizon` 字段，每条信号标注其预测期限：

| time_horizon | 典型语言 | 有效期 |
|:---:|------|:---:|
| `intraday` | "盘中""尾盘""午后" | 当日 |
| `short` | "明天""明日""今天""短线" | 1-3 交易日 |
| `medium` | "本周""下周""近期""这波" | 1-3 周 |
| `long` | "牛市""下半年""趋势""主升浪""年底" | 1 月+ |
| `unspecified` | 无明确时间锚点 | 默认均衡 |

### 改进 3：时间加权评估

**保持四窗口（T+5/10/15/20）不变以维持可比性**，但新增时间加权综合评分。

按信号的时间维度分配各窗口权重：

| time_horizon | T+5 | T+10 | T+15 | T+20 |
|:---|---:|---:|---:|---:|
| `intraday` | 1.0 | 0.3 | 0.0 | 0.0 |
| `short` | 1.0 | 0.6 | 0.2 | 0.0 |
| `medium` | 0.6 | 1.0 | 1.0 | 0.6 |
| `long` | 0.2 | 0.4 | 0.7 | 1.0 |
| `unspecified` | 0.6 | 0.8 | 1.0 | 1.0 |

**加权综合胜率** = Σ(窗口胜率 × 权重) / Σ权重

效果：
- 鸟瞰股市 92% 是短线 → 加权分主要由 T+5/T+10 决定，T+20 几乎不影响
- 衡山佛 12% 长线 → 这部分信号的 T+5 不会拉低综合分
- 混合型博主 → 自动按信号分布平衡

### 改进 4：博主级时间维度画像

每位博主生成：
- **博主类型**：短线交易型 / 中线波段型 / 长线趋势型 / 混合型
- **时间维度分布**：各维度信号占比
- **最优窗口 + 衰减模式**：
  - `rising`（长线型）：T+5→T+20 持续提升
  - `falling`（短线型）：T+5→T+20 持续下降
  - `hump`（波段型）：T+10~T+15 最高
  - `mixed`：无清晰模式

### 改进 5：长线扩展窗口

对 `time_horizon: "long"` 的信号，额外评估 T+40 和 T+60。独立展示，不参与加权综合分。

## 七、v7 发现的新规律

### 1. 衰减模式确认博主风格

| 衰减模式 | 含义 | 典型例子 |
|:---:|------|------|
| `rising` | 长线判断型，信号随持仓时间变好 | 顺应周期看多(T+5 57.5%→T+20 69.0%)、TL阳光看多(T+5 59.3%→T+20 68.0%) |
| `hump` | 波段型，T+10~T+15 最佳 | 鸟瞰看多(T+15 最优38.1%)、云帆看空(T+5 最优48.6%) |
| `falling` | 纯短线型，T+5 最佳然后持续下降 | 梦若神机看多(T+5 最优) |
| `mixed` | 无清晰窗口模式 | TL阳光看空 |

### 2. 加权修正的方向

v7 加权后，短线博主得分变化方向：

| 场景 | 变化 |
|------|------|
| 短线博主 + T+20 最好 | 加权↓（如 TL阳光 看多 68%→62.6%） |
| 短线博主 + T+5 最好 | 加权↑（如 云帆 看空 39%→48.6%） |
| 混合型博主 | 变化不大（如 顺应周期 看多 69%→62.7%） |

### 3. 长线信号扩展窗口揭示深度

对 long-horizon 信号的 T+40/T+60 评估：

| 博主 | 看多 T+40 | 看多 T+60 | 解读 |
|------|:------:|:------:|------|
| 顺应周期 | 71.4% | **78.6%** | 少数长线判断极其精准 |
| TL阳光 | 71.9% | 71.0% | 偶尔的长线判断也很可靠 |
| TL阳光看空 | 21.7% | 18.2% | 长线看空完全不可靠 |

### v7 的实操价值

v7 可以回答 v6 回答不了的问题：

- 鸟瞰的看多胜率 31% → 加权 36% → 但最优 T+15 也才 38.1%，所以仍然不建议跟。但至少不是因为 T+20 噪音才这么低。
- TL阳光 54% 信号是"明天"判断 → 加权后胜率 62.6%，比 T+20 的 68% 更保守但更诚实
- 稀豹 63% vague → 他只有在少数明确表态时才值得听，其余时间都是噪音
- 顺应周期 150 条 descriptive → 他心里按摩很多，但真正的预测信号（658 条）质量稳定
- 凸教授看空加权 78.8% → 他的看空在短线窗口（T+10）最佳，适合短线逃顶参考

## 九、方法论限制（v7 依然存在的）

1. **时间维度标注基于关键词匹配**：博客可能用长线语言表达短线观点（"这是牛市的起点"可能是明天就要涨的意思），标注可能有偏差
2. **定量权重是人为设定的**：intraday 信号的 T+15 权重设为 0，但有些日内判断的涟漪效应可能持续更久
3. **长线信号样本不足**：多数博主的长线信号不到 50 条，T+40/T+60 统计不稳健
4. **去重键变更导致信号数变化**：v6→v7 信号数增加部分源于去重逻辑变化，不完全可比
5. **descriptive 过滤可能过度**：有些描述性语言暗含预测（"大盘暴涨"可能隐含"明天还会涨"），边界模糊

**v7 的核心进步：不再用一个数字排名博主，而是说"这个博主的这类信号，在这个时间窗口，可信度是多少"。**
