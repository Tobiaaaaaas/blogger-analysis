### 4.2 推荐组合：双人互补

一个人不可能同时做好抄底和逃顶——12 人中没有人两项都顶级。你需要两个人的强项互补。

| 组合 | 抄底来源 | 逃顶来源 | 适用场景 |
|------|----------|----------|----------|
| **黄金组合** | **云帆观市** 抄底 #1 | **衡山佛** 逃顶 #1 | 通用。云帆在恐慌中喊你买（"不要割肉，可以抄底了"），衡山佛在狂热中喊你卖（"紧急提示：阶段升势告一段落"） |
| **稳健组合** | **顺应周期** 抄底 #3 | **TL阳光** 逃顶 #2 | 风险厌恶型。顺应周期仓位保守（从不建议满仓），TL阳光在真正顶部以 strong 级别明确表态（"个人于 4197 附近已经逃顶"） |
| **高频组合** | **云帆观市**（日均 3 帖） | **衡山佛**（日均 3-4 帖） | 每日关注型。两人都高频输出，拐点时刻反应迅速 |
| **独立逃顶** | —（自备买入体系） | **衡山佛 + TL阳光** 双确认 | 已有自己的买入框架，仅参考他人卖出时机 |

### 4.3 双确认机制

| 场景 | 信号组合 | 行动 |
|------|----------|------|

## 五、使用原则

### 原则 1：只看博主最强的那个维度，其余忽略

```
云帆观市 → 只看暴跌恐慌中的 strong 看多（M3/M5/I9），日常 moderate 看多是噪音
衡山佛   → 只看 "紧急提示" 级别看空（I10/I12/M6），2025 式持续唱空是踏空陷阱
顺应周期 → 只看给出技术论据的拐点判断（M6 当天转空），日常短线 ignore
TL阳光   → 只看 strong 看空 + thesis 切换（牛市→熊市），每日 "明天看涨/跌" 忽略
吉星高照 → 只看喊出具体底部点位（"3040就是底部"），其余叙事无择时价值
凸教授   → 只看极端恐慌中的逆向看多（M3），其余 956 条看多都是口号复读
大盘蜂向标 → 看恐慌指数指标信号（绿柱出现/红柱变长），而非方向判断本身
```

### 原则 2：博主的弱项 = 你的反向参考

| 博主弱点 | 反向价值 |
|----------|---------|
| 衡山佛在上升段持续看空（2025 模式） | 如果他开始像 2025 年那样在 3500 就喊顶 = 牛市可能才刚开始 |
| 稀豹用 "五浪杀跌" 框架看空 | 在牛市中他又喊 "五浪杀跌" = 放心持有 |
| 凸教授喊 "下跌的可能性，依然为零" | 最高级别危险信号——M2 和 M6 顶部前他都说过这句话 |
| 梦若神机日内多空横跳 | 一天内满仓→清仓→等满仓 = 连他都混乱了，市场在关键拐点 |
| 云帆观市罕见且持续看空 | 当此永久多头开始看空不止一天 = 需极度重视（M6 已验证） |
| 顺应周期在上升段频繁喊空 | 这是他的常态——等他给出具体顶部目标价时才需要真正警惕 |

### 原则 3：区分 "顺势躺赢" 和 "择时能力"

- **凸教授 +83.13 看多**：96% 来自 M3→M4 主升浪顺势躺赢（+80.14）。去掉这一段，看多仅 +3.01——接近随机漫步。
- **鸟瞰股市 +23.92 看多**：96% 同样来自 M3→M4。"高分" 只说明参与了牛市，不说明有判断力。
- **云帆观市 +5.43 抄底**：绝对值不算最高，但分散在 5+ 个底部拐点，可复现性强，含金量远超顺势躺赢的高分。
- **衡山佛 +1.68 逃顶**：分数不大但分散在 4 个顶部拐点、连续命中、各有技术论据，可复现。

### 原则 4：根据市场阶段切换博主组合

| 市场阶段 | 侧重能力 | 推荐博主 | 原因 |
|:---|:---|:---|:---|
| **牛市主升** | 顺势持有 + 警惕顶部 | 顺应周期（方向）+ 衡山佛（顶部预警） | 顺应告诉你怎么拿，衡山佛告诉什么时候该跑 |
| **熊市/急跌** | 风险警示 + 管住手 | 大盘蜂向标（下跌定力）+ TL阳光（long 看空 thesis） | 大盘蜂在下跌中拒绝翻多，TL阳光 thesis 切换后稳定 |
| **恐慌暴跌后** | 精准抄底 | 云帆观市 + 吉星高照 | 两人在恐慌中都有验证过的精准抄底记录 |
| **震荡市** | 减少操作 | 仅参考衡山佛（区间框架）+ 大盘蜂向标（指标信号） | 其他人在震荡市中方向判断频繁出错 |

## 六、最终建议

### 博主分级

| 级别 | 博主 | 角色定位 |
|:---:|------|------|
| ⭐⭐⭐ **核心** | 云帆观市、衡山佛曰论股、顺应周期、TL阳光 | 双人互补矩阵的四个支柱——买和卖各有一流选手 |
| ⭐⭐ **辅助** | 吉星高照、大盘蜂向标 | 特定场景（恐慌抄底、下跌定力）提供增量价值 |
| ⭐ **限用** | 凸教授、来自股市的猩猩 | 凸教授仅限底部壮胆（须自备退出方案），猩猩仅限情绪温度计 |
| 🗑️ **淘汰** | **稀豹、梦若神机、鸟瞰股市、奔走的股票** | v10 证据充分，不具备任何维度的 net positive 价值 |

### 日常使用流程

1. **每天早上**：扫一眼衡山佛是否有 "紧急提示"（最高优先级——他发出这个 = 可能正在发生顶部）
2. **想知道该不该买**：等云帆观市在暴跌恐慌中发出 strong 看多 + 具体底部判断，或吉星高照喊出具体底部点位。日常 moderate 看多全部 ignore
3. **想知道该不该卖**：等衡山佛 + TL阳光的看空信号共振（特别是 strong 级别 + 具体目标位 + 与之前 thesis 明显转向）。单人短线看空忽略
4. **持仓中不安**：看顺应周期的仓位管理和技术分析（他有具体的支撑位、破位纪律和分批建仓计划）
5. **市场持续下跌中**：参考大盘蜂向标的恐慌指数——绿柱出现前不抄底，红柱变长前不减仓
6. **感知市场情绪**：扫一眼猩猩和凸教授——猩猩还在喊回调说明散户还在怕，凸教授还在喊满仓说明多头还没死心
7. **忽略所有其他人的方向判断**：他们说的其他内容大概率是噪音
