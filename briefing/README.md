# 优质博主观点简报系统（briefing）

实时追踪两批已筛选博主（对大盘观点可靠）的帖子，每档把**超短板块**（近 3 个交易日的今天/明天表态）与**波段板块**（近 7 个自然日的波段表态）分别压缩成两张固定名单速览卡，卡尾给一段跨板块收敛总结；交易日 3 推（09:30 早盘 / 13:00 午后 / 14:30 尾盘）到飞书群。

## 卡片长什么样

```
📊 早盘简报 · 09-03 周四
🕐 覆盖：超短板块：近3个交易日（09-01—09-03） · 波段板块：近7个自然日（08-27 起）
📈 上证 3961.66 +0.51% · 两市 8567亿
──────────────────────────────
⏱️ **超短(0-1日)** · 4多/2空（6/17 表态）
🔴 **云帆观市** 看多 · 今天
　重点原话：“今天的A股反弹概率还是比较高的”（今日06:55）
　摘要：缩量不悲观，认为今天反弹概率较高
🟢 **孙万林** 看空 · 明天
　重点原话：“明天还有一次大跌，做个超短”（昨日15:06）
　摘要：明天超短还要跌，反弹减仓
🌊 **波段(2日+)** · 2多/6空（8/21 表态）
🟢 **孙万林** 看空 · 波段
　重点原话：“反弹已经见顶…底部3800附近”（昨日15:06）
　摘要：反弹见顶，波段看回踩 3800 一带
…
──────────────────────────────
🧭 超短板块 4多/2空，多数看今日/明日…；波段板块 2多/6空，多数认为调整
   未结束。两层方向相反但层叠兼容：超短反弹更像波段调整中的反抽，而非
   反转信号。孙万林短线看跌、波段看空自洽。操作上，超短可轻仓博弈反弹
   快进快出；波段宜等调整充分低吸…
```

- **两个固定名单板块**（对应 `reports/top20_值得关注博主.md` 双榜）：
  - **⏱️ 超短(0-1日)** 17 人：每人只取近 3 个交易日内的「今天/明天」表态；
  - **🌊 波段(2日+)** 21 人：每人只取近 7 个自然日内的「近日/本周/下周/更长」表态。
  - 前 8 位「双板块博主」两块都上榜：同一博主按各板块口径独立抽取、互不吞并——他可能短线看反弹、波段看调整（自洽分层，不是翻转）。
- **只显示窗口内有该板块方向观点的人**；未表态者不点名、不占行、不计入表态数。板块头部计数带覆盖度：`4多/2空（6/17 表态）`。
- 板块某档零人表态 → 板块标题保留，标题下给一行提示（如「（近3日无人给出超短方向观点）」）。
- 行 = 该博主**该板块最新一条该周期表态**，带**逐字原话**（系统回填真实发帖时间）与**摘要**；无编号，按名单顺序排。
- **两板块 = 两层，跨板块方向相反是层叠不是对立**；只有同板块内真反向才算分歧（卡尾总结按此口径收敛）。

## 数据流（单次运行，v11）

```
交易日 3 档其一触发（09:30/13:00/14:30；非交易日脚本 exit 0）
  → 双板块展示窗口：short = 滚动近 3 个交易日（calendar 从首交易日 00:00 起）；
                     swing = 近 7 个自然日（从 00:00 起，覆盖周末）
  → 增量抓取新帖（since = state.last_run，抓 ALL_BLOGGERS=30 去重全集）
  → 行情背景（腾讯行情：上证/深成/创业板 + 两市成交额）
  → 按板块 DeepSeek 行抽取（每档全量重读、每板块独立 prompt/窗口；共享 8 位各抽一次）：
     超短只认 今天/明天；波段只认 近日/本周/下周/更长/结构性中期；周期越界 → 该板块不显示
     引文时间 = 系统回填该帖真实 publish_time（模型只返回帖子下标，不誊写时间）
  → 系统分档计数 board_counts（bull/bear/shown/members，未表态不计）
  → 两板块都有方向观点 → 卡尾 LLM 收敛总结一段（跨板块层叠/同板块真分歧/超短+波段操作句）；
     全零方向 → 最小卡（健康信号），不调总结 LLM
  → 渲染飞书 interactive 卡 → POST webhook → 推进 last_run/last_slot 原子写 state
```

## 依赖的父仓库资源

`briefing/` 是独立部署单元，但运行需要父仓库（`blogger_ana`）提供的：

| 资源 | 用途 |
|---|---|
| `data/posts/*.json` | 博主帖子库（增量抓取 merge 进这里，也是展示窗口的正文数据源） |
| `scripts/pipeline/scrape_toutiao.py` | 增量窗口爬虫（已加 `--out` 参数） |
| `scripts/utils/fetch_bodies_shard.py` `merge_bodies_to_posts.py` | 新帖正文补齐 |

父仓库路径默认取 `briefing/` 上一级，可用环境变量 `REPO_ROOT` 覆盖（部署时目录结构不同则设置）。

## 运行

```bash
# 本机试跑（落盘预览，不推送、不改状态）
python -m briefing.scripts.run_briefing --dry-run --slot morning --no-scrape
# 非交易日想强制试跑：
python -m briefing.scripts.run_briefing --dry-run --slot morning --skip-calendar

# cron 真实推送（自动判定时段 / 或显式指定）
python -m briefing.scripts.run_briefing --push --slot morning

# 冒烟：只抓前 3 位博主
python -m briefing.scripts.run_briefing --push --slot late --max-bloggers 3
```

依赖环境变量：`DEEPSEEK_API_KEY`（DeepSeek，写简报用）、`FEISHU_WEBHOOK_URL`（飞书群自定义机器人）。从 `briefing/.env` 或父仓库 `.deepseek_keys.env` 自动加载。

## 设计要点

- **板块即周期层**：名单固定分组，而不是按博主最新说了什么动态落档——同一博主可同时持超短与波段两档看法（如孙万林一天内既说"明天还有一次大跌"又说"反弹已见顶、底部3800附近"），两板块各显示其该周期表态，互不吞并。
- **两个窗口分离**：展示 = 各板块滚动窗口（现读主文件，随时可回看）；抓取 = 增量 since last_run（抓 30 人全集，8 位共享博主只抓一次、按两板块读两次）。
- **时效性**：博主窗口内最新帖若非本板块周期表态、更早仍在窗口内的该周期表态照常展示，并标注它真实的发帖时间；引文时间由系统从帖子回填，模型永不誊写时间。
- **不编造**：LLM 失败 / 无该板块周期观点 → 该板块不显示不计数（log）；全零方向 → 最小卡（不发心跳）。
- 时段/日期/窗口全用北京时（`BEIJING_TZ`），独立于宿主机时区。
