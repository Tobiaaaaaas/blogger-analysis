# 优质博主观点简报系统（briefing）

实时追踪两批已筛选博主（对大盘观点可靠）的帖子，每档把**超短板块**（近 3 个交易日、目标落在卡片今/下一交易日的表态）与**波段板块**（近 7 个自然日、目标周未过的波段表态）分别压缩成两张固定名单速览卡，卡尾给一段跨板块收敛总结；交易日 3 推（09:30 早盘 / 13:00 午后 / 14:30 尾盘）到飞书群。

**v12 日期锚定**：板块行头与引文时间一律以绝对日期为准——超短行头标**目标日**（如 `看空 · 09-03`），波段行头标**锚定周**（如 `看多 · 本周 08-31~09-04`）；博主帖里的相对词（今天/明天/本周/下周）一律按其**发帖日**换算成绝对目标，已过期（目标日已过 / 目标周已整体过去）的表态自动不再显示。彻底杜绝"昨天说的明天"这类错位。

## 卡片长什么样

```
📊 早盘简报 · 09-03 周四
🕐 覆盖：超短板块：近3个交易日（09-01—09-03） · 波段板块：近7个自然日（08-27 起）
📈 上证 3942.09 +0.02% · 两市 1.76万亿
──────────────────────────────
⏱️ **超短(0-1日)** · 0多/1空（1/17 表态）
🟢 **孙万林** 看空 · 09-03
　重点原话：“明天还有一次大跌，不过…做个超短，修复了就卖。”（09-02 15:06）
　摘要：看空，认为还有一次大跌，但属短期机会，可轻仓博弈修复。
🌊 **波段(2日+)** · 7多/8空（15/21 表态）
🔴 **云帆观市** 看多 · 本周 08-31~09-04
　重点原话：“本周大概率应该会呈现一个震荡上涨修复的走势”（08-31 10:14）
　摘要：看多大盘，认为震荡上涨修复，有望冲击4000点关口。
🟢 **孙万林** 看空 · 更长
　重点原话：“A股反弹已经见顶，接下来开启漫漫熊途。”（09-02 15:06）
…
──────────────────────────────
🧭 超短板块仅1人表态看空…；波段板块 7多8空，空方略占优。
```

> 上面 孙万林 的超短行：他 09-02 帖里写"明天"，系统按其发帖日换算目标日=**09-03**（=卡片当天），行头直接标 `09-03`——不再出现"昨天的明天到底指哪天"的歧义；引文时间也统一 `MM-DD HH:MM`，不用 今日/昨日 相对速览。

- **两个固定名单板块**（对应 `reports/top20_值得关注博主.md` 双榜）：
  - **⏱️ 超短(0-1日)** 17 人：每人取近 3 个交易日内的「今天/明天」表态，**只显示目标日 = 卡片当天或下一交易日**者，行头 = 目标日 MM-DD；
  - **🌊 波段(2日+)** 21 人：每人取近 7 个自然日内的「近日/本周/下周/更长」表态，本周/下周 按**发帖日**锚定到具体周一~周五周，**目标周已整体过去的剔除**，行头 = 周词（相对卡片日）+ 周日期段；近日/更长 保留原词。
  - 前 8 位「双板块博主」两块都上榜：同一博主按各板块口径独立抽取、互不吞并——他可能短线看反弹、波段看调整（自洽分层，不是翻转）。
- **只显示仍有该板块有效方向观点的人**（超短目标已兑现、波段目标周已过者自动不显示）；未表态者不点名、不占行、不计入表态数。板块头部计数带覆盖度：`4多/2空（6/17 表态）`。
- 板块某档零人表态 → 板块标题保留，标题下给一行提示（如「（暂无超短表态：无指向今/下一交易日的观点）」）。
- 行 = 该博主**该板块最新一条该周期表态**，带**逐字原话**（系统回填真实发帖时间，一律绝对 `MM-DD HH:MM`）与**摘要**；摘要不含 今天/明天/本周 等相对时间词（系统侧剥离，日期以行头/引文时间为准）；无编号，按名单顺序排。
- **两板块 = 两层，跨板块方向相反是层叠不是对立**；只有同板块内真反向才算分歧（卡尾总结按此口径收敛）。

## 数据流（单次运行，v12 日期锚定）

```
交易日 3 档其一触发（09:30/13:00/14:30；非交易日脚本 exit 0）
  → 双板块展示窗口：short = 滚动近 3 个交易日（calendar 从首交易日 00:00 起）；
                     swing = 近 7 个自然日（从 00:00 起，覆盖周末）
  → 增量抓取新帖（since = state.last_run，抓 ALL_BLOGGERS=30 去重全集）
  → 行情背景（腾讯行情：上证/深成/创业板 + 两市成交额）
  → 按板块 DeepSeek 行抽取（每档全量重读、每板块独立 prompt/窗口；共享 8 位各抽一次）：
     超短只认 今天/明天；波段只认 近日/本周/下周/更长/结构性中期；周期越界 → 该板块不显示
     引文时间 = 系统回填该帖真实 publish_time（模型只返回帖子下标，不誊写时间）
  → resolve_anchors 日期锚定：超短按引文发帖日把 今天/明天 换算成目标日，
     只留 ∈ {卡片日, 下一交易日} 的（过期自动剔除）；波段 本周/下周 锚定到发帖日
     所在周一~周五周，目标周已过剔除；行带 anchor（行头 = 纯日期/周段），
     摘要系统侧剥离 今天/明天/本周 等相对时间词
  → 系统分档计数 board_counts（bull/bear/shown/members，未表态不计）
  → 两板块都有方向观点 → 卡尾 LLM 收敛总结一段（跨板块层叠/同板块真分歧/超短+波段操作句；
     日期照抄行 anchor，禁止自行重推）；全零方向 → 最小卡（健康信号），不调总结 LLM
  → 渲染飞书 interactive 卡 → POST webhook → 推进 last_run/last_slot 原子写 state
```

## 运行

```bash
# 本机试跑（落盘预览，不推送、不改状态）
python -m briefing.scripts.run_briefing --dry-run --slot morning --no-scrape
# 非交易日想强制试跑：
python -m briefing.scripts.run_briefing --dry-run --slot morning --skip-calendar

# cron 真实推送（自动判定时段 / 或显式指定）
python -m briefing.scripts.run_briefing --push --slot morning

# 冒烟：只抓前 3 位博主
python -m briefing.scripts.run_briefing --push --slot late --max-bloggers 3
```

依赖环境变量：`DEEPSEEK_API_KEY`（DeepSeek，写简报用）、`FEISHU_WEBHOOK_URL`（飞书群自定义机器人）。从 `briefing/.env` 或父仓库 `.deepseek_keys.env` 自动加载。

## 设计要点

- **板块即周期层**：名单固定分组，而不是按博主最新说了什么动态落档——同一博主可同时持超短与波段两档看法（如孙万林一天内既说"明天还有一次大跌"又说"反弹已见顶、底部3800附近"），两板块各显示其该周期表态，互不吞并。
- **两个窗口分离**：展示 = 各板块滚动窗口（现读主文件，随时可回看）；抓取 = 增量 since last_run（抓 30 人全集，8 位共享博主只抓一次、按两板块读两次）。
- **时效性**：博主窗口内最新帖若非本板块周期表态、更早仍在窗口内的该周期表态照常展示，并标注它真实的发帖时间；引文时间由系统从帖子回填，模型永不誊写时间。
- **日期锚定（v12）**：博主原话里的相对时间词（今天/明天/本周/下周）一律按**引文发帖日**换算成绝对目标（超短=目标日 MM-DD；波段=锚定周周一~周五）。卡片只保留仍指向卡片今/下一交易日、或目标周未整体过去的表态——超短目标已兑现、波段目标周已过者自动隐去；行头与引文时间全用绝对日期，杜绝"昨天说的明天"错位。收敛总结的日期也照抄系统锚定结果、禁止自行重推。
- **不编造**：LLM 失败 / 无该板块周期观点 → 该板块不显示不计数（log）；全零方向 → 最小卡（不发心跳）。
- 时段/日期/窗口全用北京时（`BEIJING_TZ`），独立于宿主机时区。
