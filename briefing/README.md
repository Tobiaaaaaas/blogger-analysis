# 优质博主观点简报系统（briefing）

实时追踪两批已筛选博主（对大盘观点可靠）的帖子，把**超短板块**与**波段板块**各自的观点收敛成**各自一张速览卡**，交易日盘中按各自节奏推进各自的飞书群。

**v13（2026-09-03）拆两群两卡** → **v14（2026-09-04）窗口改交易日口径**：
- **⏱️ 超短卡**（17 人 · `今天/明天` 表态，扫 **前一交易日 00:00 至 now**）→ 盘中**每 30 分钟一档**（09:30/10:00/10:30/11:00/11:30/13:00/13:30/14:00/14:30/15:00）→ **旧群**。
- **🌊 波段卡**（30 人 · `近日/本周/下周/更长` 表态，扫 **前 3 个交易日 00:00 至 now**）→ 盘中**三档**（09:30/11:00/14:30）→ **新群**（env `FEISHU_WEBHOOK_URL_SWING`）。
- 窗口按**交易日**回看（非自然日）：周一早晨天然含上周五"看周一"的帖，消除 v13 已知取舍。无明确周期的波段表态（近日/更长/未提）如实标注、不编造目标日期。
- 两板块**各自读帖、各自锚定、各自计数、各自收敛总结**——卡尾只总结本板块观点，不存在"跨板块层叠/两层对立"措辞；两卡完全独立。
- **日期锚定（v12 保留）**：板块行头与引文时间一律绝对日期——超短行头=目标日（`看空 · 09-03`），波段行头=锚定周（`看多 · 本周 08-31~09-04`）。博主帖里 今天/明天/本周/下周 一律按其**发帖日**换算成绝对目标，目标已过（超短目标日≠今/下一交易日、波段目标周已整体过去）自动不再显示。
- **每档必发、无 🆕 标记**：有观点→整版全卡；本板块零表态→该板块最小卡；内容没变也照发。
- **帖子增量复用**：抓取水位 `fetched_at` 与推送水位 `last_run` 分离；行抽取缓存 `rows_cache.json`——博主窗口帖集合没变就跳过 DeepSeek 复用缓存行（缓存行每档仍重新锚定）。

## 卡片长什么样（两卡各自长这样）

```

🕐 覆盖：超短板块 前1个交易日到现在（09-02 起）
📈 上证 3942.09 +0.02% · 两市 1.76万亿
──────────────────────────────
⏱️ **超短(0-1日)** · 0多/1空（1/17 表态）
🟢 **孙万林** 看空 · 09-03               ← 行头 = 目标日（他 09-02 帖里"明天" → 09-03）
　重点原话：“明天还有一次大跌，不过…做个超短，修复了就卖。”（09-02 15:06）
　摘要：看空，认为还有一次大跌，但属短期机会，可轻仓博弈修复。
──────────────────────────────
🧭 超短板块仅1人表态看空…（只讲超短这一层）
```

```
📊 波段早盘 09:30 · 09-03 周四
🕐 覆盖：波段板块 前3个交易日到现在（08-31 起）
📈 上证 3942.09 +0.02% · …
──────────────────────────────
🌊 **波段(2日+)** · 2多/4空（6/30 表态）
🔴 **云帆观市** 看多 · 本周 08-31~09-04
🟢 **孙万林** 看空 · 更长
…
──────────────────────────────

```

> 上面 孙万林 的超短行：他 09-02 帖里写"明天"，系统按其发帖日换算目标日=**09-03**（=卡片当天），行头直接标 `09-03`；波段行同理锚到具体周段。引文时间一律 `MM-DD HH:MM`，不用 今日/昨日 相对速览。

## 板块口径

- **两个固定名单板块**（对应 `reports/top20_值得关注博主.md` 双榜）：
  - **⏱️ 超短(0-1日)** 17 人：每人取 **前一交易日 00:00 至 now**（交易日窗口）内的「今天/明天」表态，**只显示目标日 = 卡片当天或下一交易日**者，行头 = 目标日 MM-DD；
  - **🌊 波段(2日+)** 30 人：每人取 **前 3 个交易日 00:00 至 now** 内的「近日/本周/下周/更长」表态，本周/下周 按**发帖日**锚定到具体周一~周五周，**目标周已整体过去的剔除**，行头 = 周词（相对卡片日）+ 周日期段；近日/更长/未提 无明确周期者如实标注、不编造目标日期。
  - **窗口口径（v14 交易日）**：窗口按**交易日**回看（超短 前 1 个交易日、波段 前 3 个交易日，起点日 00:00 至 now；`config.WINDOW_TRADING_DAYS`，回看用 `calendar.n_trading_days_ago`），非自然日——周一早晨窗口天然含上周五帖，无 v13"周一漏帖"取舍。
- **只显示仍有本板块有效方向观点的人**（超短目标已兑现、波段目标周已过者自动不显示）；未表态者不点名、不占行、不计入表态数。板块头部计数带覆盖度：`4多/2空（6/17 表态）`。
- 板块某档零人表态 → 仍发一张该板块最小卡（区分「近窗口无人发帖」与「有人发帖但无该板块方向观点」）。
- 行 = 该博主**本板块最新一条该周期表态**，带**逐字原话**（系统回填真实发帖时间，绝对 `MM-DD HH:MM`）与**摘要**；摘要不含 今天/明天/本周 等相对时间词（系统侧剥离）；无编号，按名单顺序排。
- **总结只讲本板块**：同板块内真反向才算分歧；清一色同向/仅 1~2 人表态就直接陈述方向。同板块同方向但操作取向相反写"共识下的操作分化"。

## 数据流（单档，v13）

```
交易日盘中 30 分网格命中（config.in_intraday_grid；12:00/12:30/15:30 等伪 tick 在
  抓取/锁之前 exit 0；波段仅 SWING_TICKS 三档额外推）
  → 各板块滚动窗口（v14 交易日）：short = 前一交易日 00:00 → now；swing = 前 3 个
    交易日 00:00 → now（config.WINDOW_TRADING_DAYS；起点日由 calendar.n_trading_days_ago）
  → 增量抓取新帖（since = fetched_at 爬虫水位，抓 ALL_BLOGGERS=40 去重全集）——
    抓取+merge 完成即写 fetched_at=wall（不等推送成败）
  → 行情背景（腾讯行情：上证/深成/创业板 + 两市成交额）一次，两卡共用
  → 逐板块：读窗口帖 → DeepSeek 行抽取（rows_cache 命中则跳过 LLM 复用缓存行；
    缓存行每档仍 resolve_anchors 重新锚定）→ 只保留 has_view 本板块周期行
  → resolve_anchors 日期锚定 + 过期剔除（行带 anchor）
  → board_counts 系统计数 → 有方向观点 → summarize_board 本板块收敛总结一段 + 全卡；
    零表态 → 本板块最小卡
  → 各板块渲染成独立 interactive 卡 → 各推各群（render.webhook_for 读
    WEBHOOK_ENV；该板块 webhook 缺失按失败处理，绝不回落 FEISHU_WEBHOOK_URL）
  → 全板块推完推进 last_run/last_slot 原子写 state；历史文件名
    {wall:%Y%m%d}_{HHMM}_{board_key}.json
```

## 运行

```bash
# 本机试跑（落盘预览，不推送、不改状态）：
python -m briefing.scripts.run_briefing --dry-run --time 09:30 --board both --no-scrape
python -m briefing.scripts.run_briefing --dry-run --time 11:00 --board swing --no-scrape --skip-calendar

# 生产调度（墙钟判定板块与档位；非交易日/离网格自动 exit 0）：
python -m briefing.scripts.run_briefing --push

# 暖场/手动补推双群（跳过门禁）：
python -m briefing.scripts.run_briefing --push --time 09:30 --board both

# 冒烟：只抓前 3 位博主
python -m briefing.scripts.run_briefing --push --board short --max-bloggers 3
```

`--time HH:MM` 只覆盖**决策时刻**（窗口/锚定/标题措辞），state/历史文件名/水位一律用真实墙钟。依赖环境变量：`DEEPSEEK_API_KEY`（DeepSeek）、`FEISHU_WEBHOOK_URL`（超短群）、`FEISHU_WEBHOOK_URL_SWING`（波段群）。从 `briefing/.env` 或父仓库 `.deepseek_keys.env` 自动加载。

## 设计要点

- **两群两卡两总结**：名单固定分组，各自只谈各自板块周期；卡尾总结绝不掺另一板块，杜绝"跨板块层叠/对立"措辞。
- **两窗口分离**：展示 = 各板块滚动窗口（现读主文件）；抓取 = 增量 since `fetched_at`（40 人全集，共享博主只抓一次、按两板块各读各的窗口）。
- **每档必发**：有观点整版、空板最小卡；无 🆕 比较标记——盘中 30 分节奏下"变化"由人眼对比上一卡。
- **增量省费**：行抽取缓存 rows_cache.json（指纹 = 窗口帖集合含正文内容），博主窗口帖没变 → 跳过 DeepSeek 复用缓存行（引文时间落窗为二道防御）；缓存的是未锚定行，目标日随卡片日变 → 每档仍重新锚定。每档每板块仅一次本板块收敛总结（行情/措辞最新）。
- **水位分离**：`fetched_at`（抓完即写）与 `last_run`（推完才写）分开——推送失败下一档不重抓已抓过的增量；webhook 失败有错误心跳。
- **不编造**：LLM 失败 / 无该板块周期观点 → 本板块不显示不计数（log）；板块 webhook 缺失 → 该板块失败心跳，绝不误发另一群。
- 时段/日期/窗口全用北京时（`BEIJING_TZ`），独立于宿主机时区。
