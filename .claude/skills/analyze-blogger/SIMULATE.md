# 博主仓位模拟 Skill

基于博主的公开仓位披露，模拟其组合净值曲线。当博主帖子中包含具体仓位构成和操作记录时，可以独立于其方向判断信号，还原其真实账户表现。

---

## 前提条件

- 博主在帖子中**公开披露仓位**：持仓标的 + 各占比（如"1成银行""3成创业板"）
- 博主披露**操作记录**：买入/卖出/加减仓的具体点位和仓位
- 博主披露频率足够追踪仓位变化（至少每周 1 次）

## 标的映射规则

博主使用的通俗标的名称 → 可交易的宽基指数：

| 博主标的 | 映射指数 | 理由 |
|:---|:---|:---|
| 老登 (大盘蓝筹股) | 上证50 | 银行、白酒、保险、券商为核心成分 |
| 金融 | 上证50 | 同上 |
| 银行 / 保险 / 券商 / 证券 | 上证50 | 招行、平安、中信证券等 |
| 白酒 / 酒 | 上证50 | 茅台为第一权重 |
| 宽基 / 上证综指 / 上证 | 沪深300 | 最接近上证综指的大盘基准 |
| 上证50 / 沪深300 | 自身 | 直接对应 |
| 创业板 | 创业板指 (399006) | 直接对应 |
| 科创 | 科创50 (000688) | 直接对应 |
| 双创 | 50%创业板 + 50%科创50 | 合成映射 |
| 创新药 / 药 | 中证500 | 中小盘成长，医药创新企业集中 |
| 中证500 / 中证1000 | 自身 | 直接对应 |
| 小登 (小盘股) / 题材股 | 中证1000 | 小盘成长代表 |

**不可映射的标的**（需单独处理或忽略）：

| 标的 | 处理方式 |
|:---|:---|
| 个股（具体股票） | 需获取个股行情；短期无法自动化 |
| 海外标的（美股/港股） | 需获取境外数据 |
| 商品（黄金/原油） | 需获取期货数据 |

## 提取流程

### Step 1: 帖子全文读取

读取博主全部 2026 年帖子（`data/posts/<博主名>.json`），不依赖 LLM 信号标注——仓位提取与方向判断是**独立的两个维度**。

### Step 2: 仓位快照提取

对每条帖子，搜索以下模式：

**A. 持仓快照**：
```
模式: [数字] [标的]
例:  "1证券，1保险，1白酒，1双创，1创业板，3上证综指"
     "仓位7成"
```

**B. 操作记录**：
```
模式: [点位] [进/出/加/减/抛] [数字]成 [标的]
例:  "在3820减掉了上周五3795进的1成仓"
     "在3870进了1成宽基"
     "把1成创新药减了"
     "尾盘买进1成科创50"
```

**C. 仓位总结**：
```
模式: 仓位[数字]成
例:  "仓位降到4成"
     "目前仓位是3成宽基+2成金融"
```

### Step 3: 时间线构建

按 `publish_time` 排序所有快照和操作，构建仓位变化时间线：

```json
[
  {
    "date": "2026-07-13",
    "description": "银行1+保险1+券商1+药1+酒1",
    "positions": {"SH50": 3.0, "CSI500": 1.0, "SH50": 1.0},
    "total_units": 5.0,
    "cash_units": 5.0
  },
  ...
]
```

### Step 4: 净值模拟

参考 `scripts/simulate_nav.py`：

1. 初始化：NAV = 1.0, 无持仓
2. 按交易日逐日遍历
3. 每天检查是否有新的仓位快照 → 如有，更新持仓结构
4. 每日收益 = Σ(各指数当日涨跌幅 × 该指数仓位) / 总仓位单位(10)
5. NAV *= (1 + 每日收益)
6. 产出每日 NAV 序列

**仓位假设**：
- 仓位快照之间的日期：沿用最近一次公开的仓位（不做日内推测）
- 现金部分不产生收益
- 仓位变化发生在快照日收盘（按当日收盘价换仓）

## 对比方向信号

仓位模拟的净值曲线可以与 v11 信号评分独立对比：

| | 方向信号评分 | 仓位模拟 |
|:---|:---|:---|
| 数据来源 | LLM 标注的 direction | 帖子中的仓位/操作披露 |
| 依赖 | 信号方向 + time_horizon | 仓位比例 + 指数价格 |
| 回答 | 博主判断方向的能力 | 博主实际操作赚了多少钱 |
| 局限 | 无法反映仓位管理 | 仅适用于公开仓位的博主 |

两者应该是互补的——方向判断好 + 仓位管理好 = 优秀交易者；方向判断好 + 仓位管理差 = 纸上谈兵。
