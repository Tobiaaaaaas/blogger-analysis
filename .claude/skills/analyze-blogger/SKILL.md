# 博主分析 Skill

分析财经博主的大盘预测能力。默认平台为今日头条，核心关注大级别拐点判断而非日间波动。

> 大盘 = 市场 = 上证 = 上证综指。全文等价。复述 SKILL 中"大盘方向判断"即指上证综指择时。

## 用法

```
/analyze-blogger <博主名称> <帖子链接>
```

示例：
```
/analyze-blogger 顺应周期 https://www.toutiao.com/w/1872013328886923/
```

如未提供参数，Skill 会询问。

## 工作流

### Step 1: 爬取帖子

```bash
cd <项目根目录> && python scripts/scrape_toutiao.py <帖子链接>
```

- 从帖子链接自动提取 token 和用户主页，翻页获取全部帖子
- **覆盖时间与大盘分析对齐**：需获取从 2024 年 6 月至今的所有帖子
- 爬虫 target 已设为 5000，确保不遗漏早期帖子
- 输出到 `data/posts/<博主名>.json`（通过 `--name <博主名>` 参数指定）

如果帖子已爬取且覆盖到 2024 年 6 月，可以跳过此步。

### Step 1.5: LLM 信号提取

> **v10 变更**：全量读取帖子，LLM 逐条标注信号。不再分片、不再正则匹配。

**整个过程不能用关键词匹配或正则表达式来筛选或标注。** 每一条帖子的每一个标注字段（direction/strength/specific/time_horizon/predictive），都必须由 LLM 通过理解帖子语义来判定，而非依赖关键词列表。

一次性读完全部帖子，用 LLM 判断每条帖子是否包含方向信号并逐条标注。

**提取为信号**的原则：整条帖子内容中有对上证/大盘/市场的方向上明确的、非模糊的预测。LLM 不应机械地逐项检查，应整体判断：**这篇帖子表达了对大盘未来的明确方向预测吗？** 如果答案是肯定的，就提取信号；如果答案否定的，就不提取。

> **默认规则**：帖子中未写明任何指数或板块的名称，默认该帖子是对上证综指/大盘的判断，应提取信号。

**信号标注字段**：LLM 必须通过理解帖子的完整语义来判断并标注，不能依赖关键词匹配。

- `direction`: bullish / bearish
- `strength`: strong / moderate
  - `strong` — 措辞坚决（"一定""必将""满仓""清仓""坚决"）+ 给出具体点位/仓位
  - `moderate` — 有方向判断但措辞温和（"偏多""倾向于""大概率""有望"）
- `specific`: explicit_action / directional_clear / directional_vague / descriptive
  - `explicit_action` — 给出操作指令（加仓/减仓/买入/卖出/抄底/逃顶）+ 配合个人操作
  - `directional_clear` — 明确方向但无操作指令（"明天看涨""调整未结束"）
  - `directional_vague` — 骑墙+弱信号，不符合"明确方向预测"的提取原则，不提取
  - `descriptive` — 有方向词但无预测意图，不符合提取原则，不提取
- `predictive`: true / false
- `time_horizon`: intraday / short / medium / long / unspecified
  - `intraday` — 博主的判断仅针对当日（"下午拉""尾盘跳水""今天收阳"）
  - `short` — 1-2 天（"明天涨""明天调整"）
  - `medium` — 1 周以上（"本周""下周""这波"）
  - `long` — 1 月以上（"牛市""下半年""趋势""主升浪"）
  - `unspecified` — 无明确时间范围

> **time_horizon 标注原理**：LLM 必须通过理解帖子的完整语义来判断时间维度，**不能依赖关键词匹配**。当帖子同时包含不同级别的时间信息时，以最长的有效时间维度为准——因为即便博主说了"下午发力"，如果它的理由和背景是"牛市下半场即将开启"，那就应该是波段级（medium/long），而非超短线。
- `evidence`: 帖子原文（关键句，≤300字）
- `publish_time`: 帖子发布时间（YYYY-MM-DD HH:MM 格式），用于判定参考价格

### Step 4: 对照分析（核心）

**你必须自己完成分析，不依赖任何规则脚本。**

#### 4.1 对照拐点

对 `market_analysis.md` 中的每个 **Major 拐点**（M1-M8）：
- 找到博主在拐点前后的帖子
- 对照博主的判断与市场实际走势
- 应用下面的 6 条评估原则
- 对 **Intermediate 拐点**（I1-I15）选择性分析，只分析博主有明确表态的

#### 4.2 按以下 6 条原则逐拐点评判

**原则 1：拐点参考知识库，不再自行判断**
市场拐点已由 `market_analysis.md` 给出。你的任务是**对照博主的判断和知识库中的拐点**，而非重新发现拐点。

**原则 2：只看大节点，忽略日间噪音**
日内/次日的涨跌判断不计入核心评估。真正有价值的是博主在阶段顶部、底部、趋势反转处的判断。

**原则 3：越明确越有分量**
模糊的"可能涨也可能跌"没有评估价值。给出了具体点位、明确仓位建议（如"在3960加1成"）的观点，无论对错都是有价值的——对了说明能力强，错了也能验证其框架是否靠谱。明确性本身就是一种敢于负责的态度。

**原则 4：最终标准——跟随操作会不会有重大损失**
这比准确率更重要。追问：如果按照博主的建议操作，会不会在顶部追高被深套？会不会在底部割肉？会不会错过大的波段行情？好的博主不一定每次都对，但他的框架能在看错时保护跟随者。

**原则 5：看多/看空分离——同一个人抄底和逃顶能力不可混评**
一个博主在顶部看空极准，不代表他在底部看多也可靠。评估时必须将看多（抄底）和看空（逃顶）作为两个独立维度分别评分。跟随者需要知道：**这个博主告诉我"什么时候买"靠谱，还是告诉我"什么时候卖"靠谱？**

**原则 6（v10 重写）：拐点线段领先性因子（return）**
评估不再使用固定 T+N 窗口，也不使用"拐点附近/趋势段"二值分类。市场的自然结构是拐点之间的线段。每条信号用 **return 因子**（潜在最大收益）连续缩放得分：

```
return = |下一个拐点价格 - 信号参考价格| / |信号参考价格|
score = strength_base × direction_sign × return
```

- **return**：距下一拐点还需涨/跌的百分比。return 越大 → 领先性越强 → 赏罚越重。return 趋近 0 → 末期跟风无价值 → 得分趋近 0
- 方向对 = +，方向错 = -；strength_base = 2(strong) 或 1(moderate)

核心逻辑：
- 上升段：刚离开底部看多 → 多加分（领先性高）；接近顶部看多 → 少加分（末期跟风）；刚离开底部看空 → 多扣分；接近顶部看空 → 少扣分
- 下降段：刚离开顶部看空 → 多加分（领先逃顶）；接近底部看空 → 少加分（唱空不稀奇）；刚离开顶部看多 → 多扣分；接近底部看多 → 少扣分

#### 4.3 拐点线段评估（打分制）

> **v10 重大变更**：弃用 T+N 窗口快照和"拐点附近/趋势段"二值分类，改为连续 return 因子（潜在最大收益）。

##### 4.3.1 线段模型

市场拐点由 `market_analysis.md` 定义（M1-M8 + I1-I15）。相邻拐点之间形成**线段**，方向由两端拐点类型决定：

- **上升段**：从底部拐点到下一个顶部拐点
- **下降段**：从顶部拐点到下一个底部拐点

##### 4.3.2 return 因子计算

对每条信号，计算它在该线段中的**潜在最大收益**：

```
return = |下一拐点价格 - 信号参考价格| / |信号参考价格|
```

**信号参考价格**（根据帖子发布时间和大盘数据判定）：

- 当天**有大盘数据**（交易日）：
  - 开盘前（<9:30）→ 使用**当天开盘价**（判断未经市场检验）
  - 盘中（9:30-15:00）→ 使用**当天收盘价**（博主看到了当天走势，收盘价反映当日结果）
  - 收盘后（>15:00）→ 使用**下一个交易日开盘价**（当天收盘已发生，判断尚未经检验）
- 当天**无大盘数据**（非交易日）→ 使用**下一个交易日开盘价**
- 发布时间未知或无法解析 → 默认使用当天收盘价（如有大盘数据）或下一个交易日开盘价

- 如果信号价格已越过下一拐点价格，return = 0

> 例：M5→M6 上升段，终点 M6 收盘 4178。
> 信号 3/25 收盘 3910，return = |4178-3910|/3910 = 0.069（距顶部还有 6.9% 空间）。
> 信号 5/12 次日开盘 4205（已越过 M6），return = 0。

##### 4.3.3 打分规则

```
direction_sign = +1（看多与上升段方向相同 / 看空与下降段方向相同）或 -1（方向相反）
strength_base   = 2（strong）或 1（moderate）
score           = strength_base × direction_sign × return
```

| 场景 | return | strong 得分 | moderate 得分 |
|------|:---:|:----------:|:------------:|
| 领先判断（刚离开拐点） | 较大 | + 赏 / - 罚 | + 赏 / - 罚 |
| 接近下一拐点 | ~0 | 0 | 0 |

return 表示距下一拐点还需涨/跌百分之多少。return 越大 = 领先性越强、赏罚越重；接近 0 = 末期跟风无价值。


##### 4.3.4 四个分数（看多看空永远分离）

```
① 综合看多得分 = 所有 bullish 信号的分数之和（每条 = strength × return，方向对+，方向错-）
② 综合看空得分 = 所有 bearish 信号的分数之和
③ 抄底得分 = 底部拐点 ±1天（共三个交易日）内的 bullish 信号分数之和（衡量博主底部瞬间的抄底表态）
④ 逃顶得分 = 顶部拐点 ±1天（共三个交易日）内的 bearish 信号分数之和（衡量博主顶部瞬间的逃顶表态）
```

拐点类型判定：
- **底部拐点**：M1(2690)、M3(3041)、M5(3795)、M8(3741)、I1(3262)、I5(3161)、I9(3816)、I13(3928)
- **顶部拐点**：M2(3674)、M4(4034)、M6(4259)、M7(4380)、I2(3452)、I6(3426)、I10(4191)、I12(4197)、I14(4175)

（I3、I4、I7、I8、I11、I15 视 market_analysis.md 的具体定义判定）

> 注：抄底/逃顶得分用 ±1天（共三天）筛选——衡量博主**在拐点瞬间是否发声**，而具体分值由 return 公式决定。

**必须包含**：

2. **四个分数汇总**：

##### 4.3.6 定性分析注意事项

除了 return 分数，LLM 定性分析时还需关注博主在每条线段内的**态度一致性**：

- **持续看多/看空**：博主在整个线段中方向始终如一。如果对了→信念坚定有远见；如果错了→顽固不化
- **摇摆不定**：博主在线段内一会儿多一会儿空（如 M6→I13 段的大盘蜂向标：先空转多再转空）。这种"多空反复横跳"本身就是负面信号——连方向都拿不准的博主不可跟
- **一次性表态**：博主只在拐点附近表态一次，随后沉默。表态对了→有远见；表态错了→一次失误

报告中须以线段为单位总结博主的态度模式，比如"该线段中博主持续看多 17 条，态度一致但方向错了"或"该线段中博主在 5/27 由空转多，之后连续喊多 12 条直至线段结束"。

#### 4.4 评估流程总结

评估流程分两步：

1. **拐点线段评估（§4.3）**：所有信号对照线段模型打分，产出四个分数
2. **LLM 定性分析（§4.1-4.2）**：对照拐点逐条分析博主的代表性判断，引用原文，给出 nuanced 评价

互相验证：线段打分提供量化框架，LLM 定性提供深度解读。如有矛盾（如分数高但 LLM 发现博主只是喊口号），以 LLM 定性为准并解释原因。

## 注意事项

- **只分析、不预测**：你的任务是评估博主的过去表现，不是对未来走势发表观点
- **不要刻板打分**：避免"60%准确率"这类机械统计，用四个分数 + nuanced 定性评价
- **引用原文**：关键判断要引用博主的原话，让读者自己判断
- **保持诚实**：博主没有判断的拐点就说没有，不要强行找预测
- **注意时期背景**：牛市中的看多和熊市中的看多，含金量完全不同
- **分数解释要谨慎**：高分不一定代表能力强（可能只是顺势躺赢），低分不一定代表差。重要的是博主在拐点处的表现
- **互相比对验证**：线段打分提供量化框架，LLM 定性提供深度解读。如有矛盾，以 LLM 定性为准并解释原因
