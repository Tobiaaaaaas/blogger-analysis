# 博主分析 Skill

分析财经博主的大盘预测能力。默认平台为今日头条，核心关注拐点判断和拐点之间趋势判断。

> 大盘 = 市场 = 上证 = 上证综指。全文等价。复述 SKILL 中"大盘方向判断"即指上证综指择时。

## 用法

```
/analyze-blogger <博主名称> <帖子链接>
```

示例：
```
/analyze-blogger 顺应周期 https://www.toutiao.com/w/1872013328886923/
```

如未提供参数，Skill 会询问。

## 工作流

### Step 1: 爬取帖子

```bash
cd <项目根目录> && python scripts/pipeline/scrape_toutiao.py <帖子链接>
```

- 从帖子链接自动提取 token 和用户主页，翻页获取全部帖子
- **覆盖时间与大盘分析对齐**：需获取从 2024 年 6 月至今的所有帖子
- 爬虫 target 已设为 5000，确保不遗漏早期帖子
- 输出到 `data/posts/<博主名>.json`（通过 `--name <博主名>` 参数指定）

如果帖子已爬取且覆盖到 2024 年 6 月，可以跳过此步。

### Step 1.5: LLM 信号提取

> **v12 变更**：全量读取帖子，LLM 逐条标注信号。不再分片、不再正则匹配。

**整个过程不能用关键词匹配或正则表达式来筛选或标注。** 每一条帖子的每一个标注字段 (direction/strength/time_horizon)，都必须由 LLM 通过理解帖子语义来判定，而非依赖关键词列表。

一次性读完全部帖子，用 LLM 判断每条帖子是否包含方向信号并逐条标注。

**提取为信号**的原则：整条帖子内容中有对上证/大盘/市场的方向上明确的、非模糊的预测。LLM 不应机械地逐项检查，应整体判断：**这篇帖子表达了对大盘未来的明确方向预测吗？** 如果答案是肯定的，就提取信号；如果答案否定的，就不提取。

> **默认规则**：帖子中未写明任何指数或板块的名称，默认该帖子是对上证综指/大盘的判断，应提取信号。
>
> **发布日期未知**：如果帖子的发布日期无法确定，则不提取为信号。
>
> **信号时间范围**：只提取 2026 年 1 月 1 日及之后发布的信号。

**信号标注字段**：LLM 必须通过理解帖子的完整语义来判断并标注，不能依赖关键词匹配。

- `direction`: bullish / bearish
- `strength`: strong / moderate
  - `strong` — 措辞坚决（"一定""必将""满仓""清仓""坚决"）
  - `moderate` — 有方向判断但措辞温和（"偏多""倾向于""大概率""有望"）
- `time_horizon`: short / medium / long / unspecified
  - `short` — 3天内预测（T ~ T+2，"明天涨""下午反弹"，包括日内）
  - `medium` — 预测周期 T+3 到 1 个月，更关注 1-2 周（"下周""月中""月底前"）
  - `long` — 预测周期 1 个月及以上（"下个月""下半年""牛市""明年"）
  - `unspecified` — 无明确时间范围

> **time_horizon 标注原理**：LLM 必须通过理解帖子的完整语义来判断时间维度，**不能依赖关键词匹配**。LLM 必须理解整个帖子的信号针对的预判周期，不能按照一句话以偏概全。当帖子同时包含不同级别的时间信息时，以信号针对的预判周期来标注该帖子的 time_horizon。
> **平仓信号**：博主的平仓信号本身表达方向观点。若博主之前持有多头仓位，发出平仓信号则等效于 bearish（卖出/减仓）；若之前持有空头仓位，发出平仓信号则等效于 bullish（买入回补/加仓）。
- `evidence`: 帖子原文（关键句，≤300字）
- `publish_time`: 帖子发布时间（YYYY-MM-DD HH:MM 格式），用于判定参考价格

### Step 4: 对照分析（核心）

#### 4.1 拐点线段评估（打分制）

##### 4.1.1 线段模型

市场拐点由 `market_analysis.md` 定义（M1-M7 + I1-I12）。相邻拐点之间形成**线段**，方向由两端拐点类型决定：

- **上升段**：从底部拐点到下一个顶部拐点
- **下降段**：从顶部拐点到下一个底部拐点

##### 4.1.2 信号参考价格（定价规则）

**信号参考价格**（根据帖子发布时间和大盘数据判定）：

- 当天**有大盘数据**（交易日）：
  - 开盘前（<9:30）→ 使用**当天开盘价**（判断未经市场检验）
  - 盘中（9:30-15:00）→ 使用**当天收盘价**（博主看到了当天走势，收盘价反映当日结果）
  - 收盘后（>15:00）→ 使用**下一个交易日开盘价**（当天收盘已发生，判断尚未经检验）
- 当天**无大盘数据**（非交易日）→ 使用**下一个交易日开盘价**
- 发布日期已知但具体时间未知 → 默认使用下一个交易日开盘价

> **T 日**即参考价对应的交易日：
> - 信号在开盘前/盘中发出 → T 日 = 信号日（参考价 = 当日开盘/收盘）
> - 信号在收盘后/非交易日发出 → T 日 = 下一个交易日（参考价 = 下一日开盘）
> - 时间未知 → T 日 = 下一交易日

##### 4.1.3 v12 单因子打分规则

**唯一因子 — return**：信号所在线段中到下一拐点的潜在最大收益。

```
return = |下一拐点价格 - 信号参考价格| / |信号参考价格|
```

**下一拐点价格**：从 `knowledge/market_analysis.md` 直接读取。该文档 §五 列出了全部 Major + Intermediate 拐点的日期和点位，Agent 打分时必须逐一引用——不自行推算、不等价于收盘价。定价规则：顶部拐点取交易日**最高价**，底部拐点取交易日**最低价**（文档中已标注极端价）。

`strength_base = 2`（strong）或 `1`（moderate）。

**打分公式**：

信号方向与线段方向一致时（看多+上升段，看空+下降段）→ 奖励：
```
score = +strength_base × return
```

信号方向与线段方向相反时（看多+下降段，看空+上升段）→ 惩罚：
```
score = -strength_base × return
```

> 注：分数以百分比表示（return 已 ×100）。博主预测对方向→得分正（大小取决于线段幅度）；预测错方向→得分负。strong 信号（×2）的影响是 moderate（×1）的两倍。

##### 4.1.4 共 14 个分数（7 个总得分 + 7 个平均分）

> **score=0 的信号不参与以下所有 14 个分数的计算**——既不参与分子（不计入总得分），也不参与分母（不计入有效信号数）。

**总得分：**

```
① 综合总得分 = 所有信号的 score 之和（score=0 的信号不参与）
② 上升段总得分 = 所有上升段内信号的 score 之和
③ 下降段总得分 = 所有下降段内信号的 score 之和
④ 抄底总得分 = 底部拐点 ±1天（共三个交易日）内信号的 score 之和
⑤ 逃顶总得分 = 顶部拐点 ±1天（共三个交易日）内信号的 score 之和
⑥ 看多总得分 = 所有 bullish 信号的 score 之和
⑦ 看空总得分 = 所有 bearish 信号的 score 之和
```

**单信号平均分（百分比）：**

```
⑧ 综合平均分 = (① / 有效信号数)
⑨ 上升段平均分 = (② / 上升段有效信号数)
⑩ 下降段平均分 = (③ / 下降段有效信号数)
⑪ 抄底平均分 = (④ / 抄底有效信号数)
⑫ 逃顶平均分 = (⑤ / 逃顶有效信号数)
⑬ 看多平均分 = (⑥ / bullish 有效信号数)
⑭ 看空平均分 = (⑦ / bearish 有效信号数)
```

> 最后一段（M7 之后）score = 0。

##### 4.1.6 定性分析注意事项

除了量化分数，LLM 定性分析时还需关注博主在每条线段内的**态度一致性**：

- **持续看多/看空**：博主在整个线段中方向始终如一。如果对了→信念坚定有远见；如果错了→顽固不化
- **摇摆不定**：博主在线段内一会儿多一会儿空（如 M6→I11 段的大盘蜂向标：先空转多再转空）。这种"多空反复横跳"本身就是负面信号——连方向都拿不准的博主不可跟
- **一次性表态**：博主只在拐点附近表态一次，随后沉默。表态对了→有远见；表态错了→一次失误

报告中须以线段为单位总结博主的态度模式，比如"该线段中博主持续看多 17 条，态度一致但方向错了"或"该线段中博主在 5/27 由空转多，之后连续喊多 12 条直至线段结束"。

#### 4.2 评估流程总结

评估流程分两步：

1. **拐点线段评估（§4.1）**：所有信号按方向一致性打分（return 单因子），产出 14 个分数（7 总得分 + 7 平均分）+ 按 time_horizon 分组得分
2. **LLM 定性分析**：对照拐点逐条分析博主的代表性判断，引用原文，给出 nuanced 评价

互相验证：线段打分提供量化框架，LLM 定性提供深度解读。如有矛盾（如分数高但 LLM 发现博主只是喊口号），以 LLM 定性为准并解释原因。

## 注意事项

- **只分析、不预测**：你的任务是评估博主的过去表现，不是对未来走势发表观点
- **不要刻板打分**：避免"60%准确率"这类机械统计，用 14 个分数 + time_horizon 分组 + nuanced 定性评价
- **引用原文**：关键判断要引用博主的原话，让读者自己判断
