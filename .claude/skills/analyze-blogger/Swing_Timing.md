# 波段择时策略

## 1. 口径与参数

| 项 | 值 |
|---|---|
| 波段委员会 | 指定的 21 位博主：云帆观市、红红火火的老牛哥、白猫财眼、大盘蜂向标、一只小小牛、孙万林、顺应周期、山顶望星空的诗人、香满衣、智由智哉、股评老陈、趋势巡航、谭阿坤、时间轨迹、刘海娃娃、四十二流光、诸葛不亮、衡山佛曰论股、微风3241、爱生活的荷叶Rp、江河之水终有入海之日 |
| 判定节奏 | 每**个交易日**一次 **14:30** 快照定调 |
| 波段观点 | 窗口 w 内，按照pub先后顺序，博主的最新一条 cat=scored 且spec≠today/t1且idx="上证指数"的信号为波段信号；该信号的d（+1/−1）为博主的波段观点。每个博主每个交易日最多只有一个波段观点；如果窗口内没有波段信号 → 该博主无波段观点。 |
| 分母 e | 窗口 w 内波段委员会所有波段观点的数量，数学上必须≤波段委员会的数量 |
| 窗口 w | **5 交易日**（决策日前第 5 交易日 00:00 → 决策 14:30 前，墙钟含周末帖） |
| 看多比例 ρ | = **多方观点 / e**（看空比例 = 1−ρ = 空方观点/e，互补）——开/平条件以它为唯一自变量（持有 = 未触发平仓门的默认状态；e=0 时 ρ 无定义、当日不动作） |
| 成交/模式 | 决策日 **15:00 收盘**成交 · `long` 仅做多 / `both` 双向（指数期货式，未计融券费/保证金）· 0 成本、全仓 0/1 |
| 净值/基准 | 收盘→收盘；样本末持仓按末日收盘强制平 · 买持 = 同期首/末交易日收盘 |

> **数据来源**：所有博主的所有波段信号、观点以及对应的具体时间已经存在于 `data/direction_signals/<博主名>.json`，请直接提取。

**信号字段**（语义同 SKILL.md §2）：

| JSON 键 | 语义字段 | 取值 |
|:---|:---|:---|
| `pub` | `publish_time` | 帖子发布时间（posts JSON 中对应 `publish_date` 字段，格式 `YYYY-MM-DD HH:MM`，用于定位参考价 bar） |
| `d` | `direction` | `1` = bullish 看多；`-1` = bearish 看空 |
| `idx` | `target_index` | 数据 key 名（默认"上证指数"）；若帖子明确提到某指数/板块则按 SKILL.md §2 映射表标注对应指数 |
| `spec` | `time_horizon` | 预测周期编码，见 SKILL.md §3 表 |
| `summary` | 信号内容摘要 | ≤50 字的预测关键句概括 |
| `cat` | 参与状态 | 只有两个值：`scored` = 参与打分；`unscored` = 不计分 |

**阈值参数**

| 参数 | 值 | 触发条件 |
|---|---|---|
| 多头开仓 `TO_LONG` | **2/3** | 空仓且ρ **>** TO_LONG 且 e>Q_open → 开多 |
| 空头开仓 `TO_SHORT` | **1 − TO_LONG = 1/3** | 空仓且ρ **<** TO_SHORT 且 e>Q_open → 开空 |
| 多头平仓 `TX_LONG` | **1/2** | 持多且ρ **<** TX_LONG 且 e>Q_exit → 平多 |
| 空头平仓 `TX_SHORT` | **1 − TX_LONG = 1/2** | 持空且ρ **>** TX_SHORT 且 e>Q_exit → 平空 |
| 开仓法定人数 `Q_open` | **10** | e **>** Q_open为开仓的必要不充分条件 |
| 平仓法定人数 `Q_exit` | **10** | e **>** Q_exit为平仓的必要不充分条件 |


## 2. 状态机

```
当日判定，输入：现持仓 pos∈{0,±1}，当日 e、多方观点 bull → ρ = bull/e。

如有持仓（pos≠0）：
平仓门：
  if 持多 且 ρ < TX_LONG 且 e > Q_exit → 平多（目标 0）
  if 持空 且 ρ > TX_SHORT 且 e > Q_exit → 平空（目标 0）
  其余情况不平仓

如空仓（pos=0）：
开仓门：
  if ρ > TO_LONG 且 e > Q_open → 开多（目标 1）
  if ρ < TO_SHORT 且 e > Q_open → 开空（目标 -1）
  其余情况不开仓
```

> 所有比较均为**严格不等**：ρ 恰等于阈值（如恰 2/3、恰 1/2）不触发开/平，维持原持仓。

> **同收盘换向**：平仓门与开仓门在同一判定内**依次执行**——持仓腿平出（目标 0）后，若当日开仓门**反方向**亦通过（both：持多且 ρ<TO_SHORT、持空且 ρ>TO_LONG，均需 e>Q_open），目标直接取反方向，同一 15:00 收盘完成 +1↔−1 换向（无隔日空仓）；`long` 模式开仓门不判开空，持多平出后只到 0 持币。

- `long` 模式 pos∈{0,1}：开仓门只判开多（ρ<TO_SHORT 不触发开空、保持持币）；平仓门与 both 相同（持多且 ρ<TX_LONG 且 e>Q_exit → 平多）。

## 3. 回测样本口径（研究侧）

回测（`research/combo/run_hyst.py`）只在**语料 100% 覆盖的干净决策日**取样：当日任一委员会成员存在
"右侧漏抽"（`data/direction_signals` 抽取止于其最近信号日 LS、而 `data/posts` 显示其后仍发帖 LP>LS，真实帖
可能落入窗口 w）→ 该日跳过、不计入样本。当前样本 = **150 个干净日 · 2026-01-05 → 2026-08-17**；右缘由漏抽
决定（08-18 起逐日有未覆盖成员）、非行情或数据末日，补抽（`--runs 1`）后可自动前移。实盘实时卡每个交易日
照常 14:30 快照推送，不受此限。
