# 博主跟随策略指南

> 基于 2024.06 ~ 2026.07 覆盖期内 8 位博主的双轨定量评估。
> 方法论：看多/看空分离评估 + 反向风险聚焦 + strong vs moderate 分层。
> 评估窗口：T+5 / T+10 / T+15 / T+20。

---

## 一、评估框架

### 两个独立维度

博主能力 = **看多/抄底能力** ║ **看空/逃顶能力**（各自独立，不可混评）

### 核心指标

| 指标 | 含义 |
|------|------|
| T+20 胜率 | 信号发出后 20 个交易日方向正确的比例 |
| 最大回撤（看多） | 跟随买入后最惨浮亏多少 |
| 最大踏空（看空） | 跟随卖出后最大错过涨幅多少 |
| 不利>3%占比 | 多少比例的信号曾让你浮亏/踏空超过 3% |
| 收益/不利比 | 赚的 ÷ 不利波动，>1 才值得跟随 |
| strong vs moderate | 博主坚决时是否比不坚决时更准 |

### 信号质量分层

- **explicit_action**（明确操作）: 博主说"加仓/减仓/买入/卖出"并配合个人操作
- **directional_clear**（明确方向）: 给出具体方向判断，如"下周将见顶""3800是底"
- **directional_vague**（模糊观点）: "可能涨也可能跌"之类，不计入评估

## 七、核心原则

1. **看多和看空分开评估**——同一个博主抄底和逃顶能力可能天差地别
2. **看反向风险，不看终点收益**——两个博主同样 T+20 +2%，回撤 -3% vs -15% 完全不同
3. **博主不坚决时的判断不如不判断**——moderate 信号在多数博主身上是负资产
4. **逃顶比抄底更稀缺**——8 位博主中 6 位的核心价值在逃顶。A 股牛短熊长，知道什么时候跑更重要
5. **所有 strong 信号平等评估**——拐点是事后才知道的，不因某个信号"发生在顶部/底部"而加权。失误严重度只看不利波动幅度
6. **信号克制是美德**——顺应周期 53 条信号中 23 条看空（52% 胜率），但 strong 看多仅 6 条（100% 胜率）。少而精的信号才有跟随价值
