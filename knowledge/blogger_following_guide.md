## 一、v10 评估框架

### 十四分数

| 总得分 | 平均分 | 含义 |
|------|------|------|
| ① 综合总得分 | ⑧ 综合平均分 | 所有信号的分数之和/平均 |
| ② 上升段总得分 | ⑨ 上升段平均分 | 上升段内信号分数之和/平均 |
| ③ 下降段总得分 | ⑩ 下降段平均分 | 下降段内信号分数之和/平均 |
| ④ 抄底总得分 | ⑪ 抄底平均分 | 底部拐点 ±1 天 bullish 信号分数 |
| ⑤ 逃顶总得分 | ⑫ 逃顶平均分 | 顶部拐点 ±1 天 bearish 信号分数 |
| ⑥ 看多总得分 | ⑬ 看多平均分 | 所有 bullish 信号分数 |
| ⑦ 看空总得分 | ⑭ 看空平均分 | 所有 bearish 信号分数 |

### 打分公式

```
A（上升+看多）：score = sbase × max(return, short_return)
B（上升+看空）：short_return > 1.5% → +sbase × short_return, else → -sbase × return
C（下降+看多）：short_return > 1.5% → +sbase × short_return, else → -sbase × return
D（下降+看空）：score = sbase × max(return, short_return)

return = |P_next_inflection - P_ref| / |P_ref|
short_return = |P_3d_extreme / P_ref - 1|
sbase = 2 (strong) 或 1 (moderate)
```

### 分数解读

- **正分**：这个维度的判断提供了正向价值。跟他的判断大概率赚钱。
- **负分**：这个维度是亏钱机器。跟他的判断大概率赔钱，或可作为反向指标。
- **零分**：在这个维度上完全缺位。

## 六、核心原则

1. **看多和看空分开**——同一个人在这两个维度可能差 100 分。稀豹看多 +5.80 vs 看空 -18.62。
2. **正分才跟，负分当反向指标**——看空负分的博主日常喊空大概率错。
3. **逃顶比抄底更稀缺**——仅 6 人逃顶 > 1.0 vs 抄底 > 1.0 的有 9 人。
4. **大盘蜂向标是 v10 最大发现**——唯一双向正分，恐慌指数可证伪。
5. **高看多分数不一定是好消息**——凸教授 +83 中 96% 来自顺势躺赢。
6. **v6 的第一名可能是 v10 的倒数第一**——稀豹 v6 看空 77% 胜率 #1，v10 看空 -18.62 #倒数第一。
7. **strong ≠ 更可靠**——凸教授 510 条 strong 看多但 0 条 strong 看空。大盘蜂向标仅 2 条 strong 看多但双向正分。
8. **只看博主最强的那个维度，其余忽略**——云帆→抄底，衡山佛→逃顶，顺应周期→仓位节奏，大盘蜂向标→指标信号。
