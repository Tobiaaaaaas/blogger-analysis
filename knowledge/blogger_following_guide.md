# 博主跟随策略指南

> 基于 8 位财经博主在 2024.06 ~ 2026.07 覆盖期内的双轨定量评估。
> 方法论：看多/看空分离评估，所有 strong 信号平等对待，失误仅按不利波动幅度排序。
> 评估窗口：T+5 / T+10 / T+15 / T+20。

---

## 一、评估框架

### 两个独立维度

看多（抄底）和看空（逃顶）分开评估——同一个博主这两项能力可能天差地别。

### 核心指标

| 指标 | 含义 |
|------|------|
| T+20 胜率 | 信号发出后 20 个交易日方向正确的比例 |
| 最大回撤 | 看多信号：跟随买入后最惨浮亏多少 |
| 最大踏空 | 看空信号：跟随卖出后最大错过涨幅多少 |
| 不利 >3% 占比 | 多少比例的信号曾让你浮亏/踏空超过 3% |
| 收益/不利比 | 平均收益 ÷ 平均不利波动，>1 才值得跟随 |

### 信号分层

| 层级 | 说明 | 计入评分 |
|------|------|:--------:|
| explicit_action | "加仓/减仓/买入/清仓"并配合个人操作 | ✅ |
| directional_clear | 明确方向判断（"下周见顶""3800 是底"） | ✅ |
| directional_vague | "可能涨也可能跌" | ❌ |

strong（措辞坚决）和 moderate（措辞温和）都计入评分，报告中分开展示（总体 / 仅 strong 双视图）。

## 八、核心原则

1. **看多和看空分开**——同一个博主抄底和逃顶能力可能天差地别
2. **看反向风险，不看终点收益**——同样 T+20 +2%，回撤 -3% vs -15% 完全不同
3. **strong 信号平等对待**——拐点是事后才知道的，失误严重度只按不利波动幅度排序
4. **博主不坚决时不如不判断**——moderate 在多数博主身上是负资产
5. **逃顶比抄底更稀缺**——8 位中 6 位的核心价值在逃顶
6. **信号克制是美德**——顺应周期 strong 看多仅 6 条但 100% 全胜，少而精才有跟随价值
