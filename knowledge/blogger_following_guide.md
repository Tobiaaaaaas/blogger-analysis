# 博主跟随策略指南

> 基于 12 位财经博主在覆盖期内的双轨定量评估（v6：激进信号提取版）。
> 方法论：看多/看空分离评估，每条方向性帖子均提取为信号，失误仅按不利波动幅度排序。
> 评估窗口：T+5 / T+10 / T+15 / T+20。
> **更新时间**：2026-07-30

---

## 一、评估框架

### 两个独立维度

看多（抄底）和看空（逃顶）分开评估——同一个博主这两项能力可能天差地别。

### 核心指标

| 指标 | 含义 |
|------|------|
| T+20 胜率 | 信号发出后 20 个交易日方向正确的比例 |
| 最大回撤 | 看多信号：跟随买入后最惨浮亏多少 |
| 最大踏空 | 看空信号：跟随卖出后最大错过涨幅多少 |
| 不利 >3% 占比 | 多少比例的信号曾让你浮亏/踏空超过 3% |
| 收益/不利比 | 平均收益 ÷ 平均不利波动，>1 才值得跟随 |

### 信号分层

| 层级 | 说明 | 计入评分 |
|------|------|:--------:|
| strong + explicit_action | 措辞坚决 + 给出操作指令 | ✅ 权重2x |
| strong + directional_clear | 措辞坚决 + 明确方向 | ✅ 权重2x |
| moderate + explicit_action | 措辞温和 + 给出操作指令 | ✅ 权重1x |
| moderate + directional_clear | 措辞温和 + 明确方向 | ✅ 权重1x |
| directional_vague | 方向含糊 | ❌ |

## 七、核心原则（v6 更新）

1. **看多和看空分开**——同一个博主抄底和逃顶能力可能天差地别。12 位中仅 4 位两项都及格。
2. **看反向风险，不看终点收益**——同样 T+20 +2%，回撤 -3% vs -15% 完全不同。
3. **strong 不等于更可靠**——凸教授/衡山/吉星/奔走的 moderate 信号反而更准，"越坚定越危险"是普遍规律。
4. **逃顶比抄底更稀缺**——12 位中仅 4 位看空胜率超 50%（稀豹 77%、凸教授 77%、梦若神机 71%、吉星 64%）。
5. **永多头逃顶为什么准？**——凸教授/稀豹这类"永多头"，只在大幅下跌后才罕见转空，顺势看空自然胜率高，但在最重要的顶部反而还在喊多。
6. **信号克制仍是美德**——顺应周期 strong 看多 109 条胜率 77%，是唯一超过 70% 的高信号量看多博主。
7. **新博主需时间验证**——梦若神机 2.5 个月数据不足以评判。鸟瞰股市存在早期数据异常。
