## 三、博主组合矩阵

### 核心逻辑：**双人互补**

每个跟随者至少需要两个博主：一个告诉你怎么买（抄底），一个告诉你什么时候卖（逃顶）。一个人不可能同时做好这两件事——12人中没有人两项都优秀。

### 推荐组合

| 组合 | 抄底来源 | 逃顶来源 | 适合场景 |
|------|----------|----------|----------|
| **黄金组合** | 顺应周期 strong 看多 | 稀豹 moderate 看空 | 通用，覆盖期表现最佳 |
| **高频组合** | TL阳光 看多方向 | 凸教授 看空 | 每日关注，信号密集 |
| **保守组合** | 顺应周期 strong 看多 | 凸教授 看空 | 逃顶信号更多（162 vs 69），统计更稳 |
| **纯逃顶组合** | — | 稀豹+凸教授 双确认 | 已有自己的买入体系，只参考卖出时机 |

### 双确认机制

当两个互补方向的博主信号共振时，可靠性显著提升：

| 场景 | 信号组合 | 行动 |
|------|----------|------|
| 买入确认 | 顺应周期 strong 入场 + TL阳光 看涨 | 果断建仓 |
| 卖出确认 | 稀豹 moderate 看空 + 凸教授 看空 | 果断减仓 |
| 买入危险 | 顺应周期看多 + 稀豹也看多 | 谨慎，稀豹看多是反向指标 |
| 卖出危险 | 凸教授看空 + 顺应周期也看空 | 加仓，顺应看空大概率错 |

## 四、如何使用这些博主的观点

### 原则 1：只看最强的那个维度，忽略其他

每个博主只取他最好的一个能力：

```
顺应周期 → 只看 strong 看多（T+20 77%），他的看空是垃圾
稀豹     → 只看 moderate 看空（T+20 ~87%），他喊多时快跑
凸教授   → 只看看空（T+20 77%），他喊多时当反向指标
TL阳光   → 只看看多方向，不要跟他的高频短线
衡山佛   → 只看 moderate 看多，他越坚决越危险
猩猩     → 只看看多，看空坚决时反着做
云帆     → 只看 strong 看多，设止损
吉星     → 只当风险预警，不做跟单
```

### 原则 2：对方博主的弱项就是你的反向参考

| 博主的弱项 | 反向价值 |
|-----------|---------|
| 顺应周期 strong 看空（15%） | 他坚决喊空 = 继续涨 |
| 稀豹 看多（30%） | 他疯狂喊多 = 危险信号 |
| 凸教授 看多（39%） | 他持续喊多说明还在涨 |
| 猩猩 strong 看空（27%） | 他自信喊空 = 做多窗口 |
| TL阳光 看空（31%） | 他喊跌时大概率涨 |

### 原则 3：看反向风险，不看收益率

同样 T+20 看起来不错，但背后的风险体验完全不同：

```
顺应周期 strong 看多：+3.48% 收益，26%概率回撤>3%
衡山佛 看多：      +1.10% 收益，27%概率回撤>3%
```

两者回撤风险相近，但顺应周期收益高出 2.38%——相同的难受程度，更好的回报。

### 原则 4：牛市不跟看空，熊市不跟看多

12 人中 8 人看空 T+20 胜率 <50%。在 2024.06-2026.07 这个整体上涨的市场中，持续看空的人被反复打脸。同样，鸟瞰/稀豹/凸教授/吉星/梦若的看多在调整市中表现惨淡。

**当前市场处于调整期（上证 3741 附近），建议：**
- 侧重逃顶信号（稀豹、凸教授），看空信号如果共振，减仓
- 谨慎对待所有人的看多——调整市中抄底大概率被套
- 顺应周期是唯一在调整市中抄底有正期望的（T+20 69%），但也等他的 strong 信号
